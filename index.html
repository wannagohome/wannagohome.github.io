Server Driven UI

네이티브 앱은 UI 하나를 고치는 데도 앱 업데이트가 필요하고, 업데이트는 사용자에게 늦게 닿습니다. 그래서 서버가 내려 주는 데이터에 따라 UI를 자유롭게 바꿀 수 있는 구조를 만들었습니다.

한 화면을 컴포넌트 단위로 쪼개고, 서버가 컴포넌트 정보를 내려 주면 앱은 그 정보대로 그립니다.

  • 성능과 코드 구조이전에 시도된 Server Driven UI는 성능이 느리고 코드 구조를 이해하기 어려웠습니다.
  • 로직 없이 기능 구현앱은 서버가 준 데이터대로 그리기만 하므로, 뷰에 로직을 직접 넣지 않고 기능을 구현해야 했습니다.
  • 동적 범위 조절네이티브 앱을 HTML처럼 전부 동적으로 그리기에는 리소스가 부족했습니다. 바꿀 수 있는 범위를 적정 수준으로 제한하면서도 범용성을 지켜야 했습니다.
